# FactoryAspects

Standalone UI style libraries, one per framework/architecture, each living in its own
top-level folder in this repo.

- **[`Blazor/`](Blazor/README.md)** — a Blazor Razor Class Library (C#). Buttons,
  cards, form inputs, layout shells, a theme switcher, and more.

More libraries for other architectures will land here over time as sibling folders.
Each library is independently installable/packaged — see that library's own README
for install steps and what it contains.
